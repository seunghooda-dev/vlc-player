MXF QC Player V.1.0 - 운영자 빠른 안내
========================================

처음 실행
---------
1. MXF QC Player.exe를 실행합니다.
2. 상단 ENV 버튼에서 VLC, FFmpeg, FFprobe, FFplay 상태가 정상인지 확인합니다.
3. 파일 추가 버튼으로 MXF 파일을 추가합니다.
4. 파일 목록에서 더블클릭하거나 CUE 버튼을 누르면 첫 프레임이 표시됩니다.
5. 기본 오디오 출력은 1/2CH입니다.

주요 버튼
---------
- CUE: 선택 파일을 비디오 스테이지에 올립니다.
- PLAY/PAUSE: 재생/일시정지입니다.
- STOP: 재생과 오디오 보조 프로세스를 정리합니다.
- 블랙: 1프레임 이상 검정 화면 구간을 수동 분석합니다.
- 뮤트: 1초 이상 무음 구간을 수동 분석합니다.
- 일괄: 파일 목록 전체를 블랙 검출 후 뮤트 검출 순서로 자동 검수합니다.
- 취소: 진행 중인 일괄 검수를 중단합니다.
- 자동저장: 일괄 검수 완료 후 QC CSV 리포트를 reports 폴더에 자동 저장합니다.
- 전체/완료/문제: 파일 목록을 검수 상태 기준으로 필터링합니다.
- 리포트: 파일 목록의 QC 결과를 CSV/TXT로 저장합니다.
- ENV: 실행 환경, 자식 프로세스, 최근 상태 타임라인을 확인합니다.
- LOG: 최근 오류 로그를 확인합니다.
- CHECK: 배포 전 확인 항목을 봅니다.
- REPORT: 진단 ZIP을 reports 폴더에 즉시 저장합니다.

문제 발생 시
------------
1. LOG 버튼에서 최근 오류를 확인합니다.
2. ENV 버튼에서 리포트 저장을 눌러 진단 ZIP을 만듭니다.
   급할 때는 상단 REPORT 버튼을 누르면 바로 저장됩니다.
3. 파일이 외장하드/NAS에 있으면 연결, 권한, 파일 잠금 상태를 확인합니다.
4. 소리만 남거나 앱이 비정상 종료되면 앱을 다시 실행하면 고아 오디오 프로세스를 자동 정리합니다.

저장 위치
---------
프로그램 파일:
C:\vld player\release\MXF QC Player V.1.0

사용자 데이터:
%LOCALAPPDATA%\MXF QC Player V.1.0

사용자 데이터에는 settings.json, archive.db, logs, tmp, backups, reports가 저장됩니다.
업데이트 시 이 폴더는 삭제하거나 덮어쓰지 마세요.

배포 전 확인
------------
프로그램을 닫고 아래 파일을 실행합니다.

preflight_check.bat

이 검사는 실행 파일, VLC/FFmpeg 도구, 쓰기 권한, 기본 실행 가능 여부와 함께
운영 안내, 업데이트 정책, 샘플 체크리스트, 바로가기 설치 파일, 아이콘,
라이선스 고지 파일 누락 여부를 경고로 표시합니다.

실제 MXF 샘플 하나를 빠르게 검증하려면:

smoke_mxf_test.bat "C:\path\sample.mxf"

정해진 방송 샘플 세트를 반복 검증하려면 BROADCAST_SAMPLE_SET.txt를 편집한 뒤:

broadcast_sample_set_validation.bat BROADCAST_SAMPLE_SET.txt

롤백
----
새 버전에 문제가 있으면 프로그램을 닫고 아래 파일을 실행합니다.

rollback_release.bat

이 작업은 프로그램 파일만 이전 백업으로 되돌립니다.
설정, 최근 파일 목록, DB, 로그는 사용자 데이터 폴더에 그대로 남습니다.
