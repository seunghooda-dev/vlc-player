# Plan: 오디오 레벨 바 16채널 확장

- 작성일: 2026-07-15
- 요구: 좌우 레벨 바가 현재 8개(좌 4 홀수 / 우 4 짝수)인데 UHD 마스터는 16채널 —
  **현재 바 크기(행 17px)를 유지**한 채 16채널 표시.

## 사실 확인 (정찰 결과)

- 측정 스레드(AudioLevelThread)는 이미 16채널 완비 — astats 1..16 생성/파싱/피크홀드 전부 16.
- 표시를 8로 막는 지점은 단 두 곳: `MeterController._on_levels`의 `[:8]` 캡(meters.py 609-616)과
  `_meter_channel_count`의 `min(8,…)`(video_panel.py 903).
- `probe()`의 `channels`는 오디오 스트림 **합계**(db_models.py 404) — 16모노/1×16ch/8×스테레오
  모든 배치에서 max(streams, channels)=16이 성립. 파이프라인 공백 없음.
- 레이아웃: 바는 가로 막대의 세로 스택. 폭(116px) 불변, 높이만 74→144(8행×17px+간격 7) 필요.
  좌측 레일은 여유 충분. **우측 레일은 하단 고정 라우드니스 미터(208px)와 좁은 창에서 충돌
  가능**(video_h<~357px) — 방치 시 겹침.

## 설계

1. `_on_levels` 캡 8→16, 홀/짝 분배 range 16으로.
2. `_meter_channel_count` min(8→16). (기존 하네스 프로브는 ≤8 입력이라 그대로 그린.)
3. 활성 레일 채널 목록: 좌 [1,3,…,15] / 우 [2,4,…,16]. 생성 시 높이 144.
4. `_resize_video_stage`에서 레일 높이를 **적응형**으로: 목표 144, 좌측은 스테이지 잔여,
   우측은 `loud_y - audio_y - 4` 상한으로 클램프(최소 39). 넓은 창에서는 17px 바 유지,
   좁은 창에서만 우아하게 축소 — 라우드니스 미터와 절대 겹치지 않음.
5. main.py 스모크의 기대 채널 목록 갱신 + **우레일↔라우드니스 비겹침 단언 추가**(기존 검사는
   video 겹침만 봄).
6. 유지: 채널 선택 체크박스 8개(출력 라우팅 — 요구 범위 밖), prepare/set_playing의 `[0]*8`
   클리어(레일이 자체 길이로 패딩 — 하네스 idle 프로브 고정 유지), 표시 텍스트 "8CH/16CH" 규칙.
